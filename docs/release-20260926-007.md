## Cambio

- Corregido `src/nicheradar/dashboard.py`: dos expresiones ternarias sueltas
  (`st.warning(...) if ... else st.info(...)`, y `st.dataframe(...) if ... else st.info(...)`)
  reemplazadas por sentencias `if/else` explícitas. El modo "magic" de Streamlit envolvía
  esas expresiones sueltas en `st.write()`, cuya introspección de código fallaba al
  toparse con un literal `{...}` multilínea, tumbando el dashboard completo con
  `SyntaxError: '{' was never closed` en cuanto había algún motivo de estado que mostrar
  (por ejemplo `budget_blocked`, presente con el radar pausado). Ningún test local cubría
  ese código con `research.reasons` no vacío, por eso pasó desapercibido en pruebas.
- Añadido `.streamlit/config.toml` con tema `light` explícito (colores iguales al CSS ya
  inyectado en `dashboard.py`). Antes las alertas nativas de Streamlit (`st.warning`,
  `st.info`, `st.error`) heredaban el tema claro/oscuro detectado del navegador de quien
  abre el dashboard, mientras el CSS forzaba fondo claro solo en el contenedor principal;
  la combinación producía texto de bajo contraste en modo oscuro.
- `Dockerfile` y `.dockerignore` actualizados para incluir `.streamlit/config.toml` en las
  tres imágenes (el `.dockerignore` es una lista de permitidos explícita).
