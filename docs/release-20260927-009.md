## Cambio

- **Navegación lateral**: se mantiene `st.radio` (no se convirtió a `st.tabs()` — cambiaría
  el modelo de renderizado, disparando las 5 páginas en cada interacción y rompiendo los
  tests de navegación). Se estilizó con CSS sobre los `data-testid` estables de Streamlit
  (`stRadio`, `stRadioGroup`, `stRadioOption`) para verse como una lista de píldoras con
  estado seleccionado resaltado en azul, usando el selector `:has(input:checked)`.
- **Resto de vistas con JSON crudo**: se agregó `render_structured()`, un renderizador
  genérico recursivo que convierte cualquier dict/lista en tablas (`st.dataframe`)
  en vez de `st.json`. Se aplicó a: agrupamiento temático, trazabilidad de afirmaciones
  y enriquecimiento LLM, métricas temporales, detalle técnico completo de la evaluación,
  comparación entre evaluaciones, evaluaciones/posiciones guardadas, publicidad (fuente/
  geografía/condiciones), Creator Fit (costes/horas/capacidad, omitiendo receta y perfil
  porque ya están editables justo debajo), resultados de escenarios y presupuesto del
  piloto. Se dejó sin tocar el único caso legítimo: el payload crudo de un proveedor
  externo en "Evidencia original" (es información opaca de terceros, no un contrato
  interno propio).
